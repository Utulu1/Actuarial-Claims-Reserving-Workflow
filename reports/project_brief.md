# Project Brief

## Business Problem

An insurance company must estimate the amount required to settle claims that have already occurred but have not yet been fully paid.

Reliable reserve estimates are essential for:

- Financial reporting
- Solvency monitoring
- Capital management
- Pricing decisions
- Regulatory compliance

The Reserving Team has received raw claims data and must first determine whether the data is suitable for actuarial analysis before estimating outstanding claims reserves.

## Project Objective

Develop a complete actuarial reserving workflow using real insurance claims data.

The workflow will include:

- Data acquisition
- Data quality assessment
- Exploratory data analysis
- Development triangle construction
- Chain Ladder reserving
- Mack Chain Ladder reserving
- Reserve diagnostics
- Professional actuarial reporting

## Expected Deliverables

- Clean reserving dataset
- Data Quality Report
- Claims Development Triangle
- Loss Development Factors (LDF)
- Chain Ladder Reserve
- Mack Reserve
- IBNR Estimate
- Professional Actuarial Report
- GitHub Documentation
